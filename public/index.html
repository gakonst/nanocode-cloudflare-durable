nanocode on Cloudflare.
Durable agents in Durable Objects.

This agent runs in a Cloudflare Durable Object: the nanocode SDK compiled to WebAssembly, with its journal in the object's own SQLite. When the object resets mid-turn, its alarm starts it again, and the turn continues from the last checkpoint. Cloudflare AI Gateway serves its model requests. Its source is gakonst/nanocode-cloudflare-durable.

Ask a question to start a turn, or type /model to choose a model.
